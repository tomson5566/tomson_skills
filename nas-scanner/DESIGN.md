# DESIGN.md

## 产品定位

NAS 勒索软件威胁扫描器 —— 面向群晖用户的安全自检工具。气质对标「医院检验科的检测报告」：冷静、精确、可读性优先，不是炫技的黑客面板。

## 气质与意象

- 关键词：检验报告、监控室、手术灯下的白
- 场景叙述：深夜运维监控室，一块浅色屏幕清晰地列出每一项指标，红色只在真正危险时出现——克制，才让告警有分量。

## 设计禁忌

- 禁止 Matrix 黑客绿、赛博朋克霓虹、满屏跳动的伪终端字符雨
- 禁止无意义的暗色模式堆砌——本工具以浅色专业仪表盘为主
- 禁止滥用红色：红色仅用于确认的威胁，告警黄用于可疑项

## Design Tokens

### 色彩

- 基底：浅灰白 `#F7F8FA`（检验单纸张）
- 卡片：纯白 + 1px 浅灰边，不用厚重阴影
- 主色：深蓝灰 `#1E3A5F`（仪器的冷静感），用于主按钮、标题强调
- 语义色：
  - 安全 `emerald-600`
  - 可疑/警告 `amber-600`
  - 威胁/危险 `red-600`
  - 信息 `sky-600`

### 字体

- 中文：Noto Sans SC（思源黑体），正文常规字重
- 等宽：JetBrains Mono / ui-monospace，用于文件路径、日志、版本号、IOC 特征——路径和代码是这款工具的主角

### 布局

- 单页应用：顶部状态栏 → 扫描配置区 → 进度区 → 报告区，纵向滚动
- 报告区按「威胁等级摘要卡 → 分类发现列表 → 处置建议」组织
- 状态变化用颜色 + 图标双重编码，不只依赖颜色

## 交互

- 扫描进度通过 SSE 流式推送，打字机式日志滚动（等宽字体、小字号）
- 按钮状态明确：扫描中禁用配置表单，进度条真实反映已扫描文件数

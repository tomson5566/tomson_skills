# 数据中台开发技能（data-platform-dev）

将《数据中台开发手册》的通用规范落地为**可执行、平台无关、可配置扩展**的 agent 技能，覆盖数据中台建设与日常数据开发全生命周期。

## 它能做什么
- 从零搭建贴源层(ods)/共享层(dwd)/应用层(ads)分层表、命名规范、公共维度/事实模型。
- 开发符合规范、可重跑（幂等）的加工 SQL，含增量合并、多表关联、窗口函数。
- 配置数据集成/同步任务、字段映射与类型对齐、水位管理。
- 设计数据服务接口，统一出参、错误码、鉴权、分页限流。
- 配置数据质量规则、对账、监控告警、调度依赖、补数重跑。
- 按规范化清单做代码评审、上线验收、交付与运维交接。

## 设计亮点：可迁移、可扩展
- **平台无关**：默认 Hive/Spark SQL，方言差异收敛在 `config/dialect.md`，新增平台=加一列配置。
- **配置驱动扩展**：业务域/来源系统/刷新周期编码全在 `config/`，企业定制=改配置，不重写规范。
- **模块化**：规范按主题拆分到 `docs/NN-*.md`，新增主题=新增一个文档+挂一个引用。
- **模板复用**：`templates/` 提供建表/增量/对账/接口/质量规则即用模板。
- **检查清单**：`checklists/` 沉淀评审 13 项与验收 15 项卡点。

## 目录结构
```
SKILL.md                  主入口：触发条件、工作流程、迁移/扩展入口
config/                   可扩展编码与方言配置层
docs/                     12 个规范专题模块
templates/                建表/加工/接口/质量规则模板
checklists/               评审与验收检查清单
```

## 使用入口
作为 agent 技能通过 `load_skill` 加载；加载后按 `SKILL.md` 的标准工作流程 A→H 执行。

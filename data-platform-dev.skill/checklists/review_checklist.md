# 代码评审要点（对应手册 11.4，13 项必检）

| 序号 | 检查项 | 检查标准 |
|---|---|---|
| 1 | 分层落点 | 表所处分层与业务角色一致，无跨层反向引用 |
| 2 | 命名合规 | 表、任务、接口命名符合命名规范 |
| 3 | 表结构 | 字段注释齐全、分区字段正确、类型与精度合理 |
| 4 | 元数据 | 粒度、来源、频率、责任人、生命周期、敏感等级已登记 |
| 5 | 血缘 | 可回溯至源系统表，字段级血缘已采集 |
| 6 | 时间参数 | 使用调度参数，无实时日期函数 |
| 7 | 依赖与并发 | 依赖节点选择准确，资源队列与并发已设置 |
| 8 | 幂等性 | 重跑结果与首次运行一致 |
| 9 | 数据核对 | 行数与关键指标汇总值与预期一致 |
| 10 | 性能 | 已按性能优化清单检查，无明显反模式 |
| 11 | 质量规则 | 已配置必要的数据质量规则 |
| 12 | 安全 | 权限、敏感字段处理符合安全规范 |
| 13 | 回退方案 | 已准备并验证回退方案 |

## 提交前快速自查（SQL 类）
- [ ] 无 `SELECT *`（除临时排障）
- [ ] WHERE 是否携带分区键 `ds='${bizdate}'`
- [ ] 分区列未被函数包装（如 `DATE(ds)`）
- [ ] 写入为 `INSERT OVERWRITE`（幂等）
- [ ] 业务日期来自调度参数，非实时函数
- [ ] 金额字段为 `DECIMAL`
- [ ] 魔法数字/字典码已映射

# 12 交付与验收

## 交付物清单
| 类别 | 交付物 |
|---|---|
| 设计类 | 需求单、数据需求说明书、模型设计说明、字段口径说明、数据资产目录 |
| 开发类 | 建表脚本、SQL 脚本、同步任务配置、接口定义、元数据登记 |
| 测试类 | 自测报告、数据核对记录（行数与汇总值比对）、性能评估记录 |
| 上线类 | 上线申请单、调度依赖配置说明、发布记录、产出验证结果 |
| 运维类 | 监控与告警配置、运维交接单、故障处置预案、回退方案 |
| 文档类 | 表注释与元数据、指标口径说明、接口文档与调用示例 |

## 验收检查表（对应手册 13.2）
见 `checklists/acceptance_checklist.md`。**逐项检查，任一项不通过即判定不通过。**

| 序号 | 检查项 | 通过标准 |
|---|---|---|
| 1 | 分层落点 | 与业务角色一致，无跨层反向引用 |
| 2 | 命名合规 | 表、任务、接口符合命名规范 |
| 3 | 表结构 | 字段注释齐全、分区正确、类型与精度合理 |
| 4 | 元数据 | 粒度、来源、频率、责任人、生命周期、敏感等级齐全 |
| 5 | 血缘完整 | 可回溯至源系统表，字段级血缘已采集 |
| 6 | 时间参数 | 使用调度参数，无实时日期函数 |
| 7 | 依赖正确 | 依赖节点准确，无冗余跨空间依赖 |
| 8 | 资源设置 | 资源队列、并发与超时已配置 |
| 9 | 幂等可重跑 | 重跑结果与首次一致 |
| 10 | 数据核对 | 行数与关键指标汇总与预期一致 |
| 11 | 性能 | 无明显反模式，已执行优化清单 |
| 12 | 质量规则 | 已配置必要数据质量规则 |
| 13 | 安全合规 | 权限与敏感字段处理符合规范 |
| 14 | 监控告警 | 失败、超时、数据量波动均有告警与处置入口 |
| 15 | 回退方案 | 已准备并验证回退方案 |

## 运维交接
| 交接项 | 交接内容 |
|---|---|
| 任务清单 | 全部上线任务名称、调度、依赖、责任人 |
| 数据资产 | 表清单、中文名、粒度、来源、消费方 |
| 监控配置 | 告警规则、通知渠道、故障处置路径 |
| 已知问题 | 遗留缺陷、限制条件、待优化项 |
| 权限清单 | 已开通账号与权限清单及回收计划 |
| 文档索引 | 需求、设计、测试、上线记录存放位置 |

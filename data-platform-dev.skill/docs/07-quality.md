# 7 数据质量规范

## 质量维度与规则分类
| 维度 | 检查对象 | 典型规则 |
|---|---|---|
| 完整性 | 字段、表、批次 | 必填字段非空率、批次到达率、表行数不为零 |
| 唯一性 | 主键、联合键 | 主键重复数、联合键重复数 |
| 有效性 | 格式、值域、精度 | 日期格式合法、编码值域匹配、金额精度合规 |
| 一致性 | 跨表、跨层、跨系统 | 源/目标行数比对、汇总值一致、字典值一致 |
| 及时性 | 调度与产出 | 约定时间窗内到达、产出时间戳符合预期 |
| 准确性 | 异常与突变 | 指标环比波动超阈值、空值率突增、分布漂移 |

## 规则设计原则
- 每张共享层表与应用层结果表至少 **1 条完整性 + 1 条唯一性** 规则。
- 贴源层表必须配置**与源端记录数比对**规则。
- 关键指标配置与上下游**汇总值一致性**规则。
- 阈值基于历史波动设定，避免无效告警。
- 规则与被检对象建立归属关系，元数据目录可查。
- 规则本身**版本化**，口径调整同步更新规则与基线。

## 数据量对账方法
```sql
-- 源端与目标端行数比对
SELECT 'source' AS side, COUNT(1) cnt FROM ods_crm_customer      WHERE ds='${bizdate}'
UNION ALL
SELECT 'target' AS side, COUNT(1) cnt FROM dwd_cst_customer_info WHERE ds='${bizdate}';

-- 主键唯一性检查
SELECT cust_id, COUNT(1) cnt FROM dwd_cst_customer_info
WHERE ds='${bizdate}' GROUP BY cust_id HAVING COUNT(1)>1;

-- 关键金额汇总比对
SELECT SUM(sales_amt) amt_sum FROM ads_cst_sales_cust_rank WHERE ds='${bizdate}';
```
完整模板见 `templates/reconciliation.sql`。

## 质量报告与问题闭环
| 环节 | 要求 | 时限 |
|---|---|---|
| 发现 | 监控告警/核查任务触发 | 实时 |
| 定位 | 通过血缘确认影响范围与消费方 | 4h |
| 修复 | 责任开发处理并重跑相关任务 | 24h |
| 验证 | 重跑后重跑规则确认恢复 | 修复后 2h |
| 通报 | 影响对外供数的通报消费方 | 修复确认后 |
| 复盘 | 重复问题根因分析并补防护规则 | 一周内 |

## 监控与告警
| 告警类型 | 触发条件 | 级别 |
|---|---|---|
| 任务失败 | 任务实例运行失败 | 高 |
| 任务未产出 | 约定时间窗无产出 | 高 |
| 数据量波动 | 行数/关键指标偏离基线 | 中 |
| 空值率异常 | 关键字段空值率突增 | 中 |
| 数据延迟 | 产出晚于 SLA | 中 |
| 接口异常 | 失败率/响应时长超阈值 | 按影响面 |

> 告警必须可处置：每条告警对应明确处置入口（任务实例、核查任务、责任人）。规则模板见 `templates/quality_rule_template.md`。

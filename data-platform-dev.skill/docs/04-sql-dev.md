# 4 SQL 开发规范

## 通用书写规范
- 关键字/函数名大写（SELECT、FROM、WHERE、GROUP BY、OVERWRITE…），表名字段名按实际大小写。
- 缩进 4 空格；子查询层级 ≤ 3 层，超过改中间表。
- **禁止 `SELECT *` 作为生产输出**。
- `INNER JOIN` 写全称；跨表关联条件必须同时含业务关联键与分区键。
- `UNION` 优先 `UNION ALL` 并显式说明去重逻辑。
- WHERE 中**禁止对分区列函数包装**（分区裁剪失效）。
- 注释用 `--`，说明口径、特殊处理逻辑与数据范围；禁止遗留调试语句。
- 常量/魔法数字提取为命名参数或公共维表，不散落 SQL。

## 建表与写入
- 建表：`CREATE TABLE IF NOT EXISTS`（重建走变更流程）。
- **默认覆盖写入保证幂等**：
  ```sql
  INSERT OVERWRITE TABLE ads_cst_sales_cust_rank PARTITION (ds = '${bizdate}')
  SELECT ...
  ```
- 追加写入 `INSERT INTO ... PARTITION` 仅限明确累积场景，任务注释须标注"非幂等，谨慎重跑"。

## 时间参数与调度日期（核心）
业务日期**必须来自调度参数**，禁止在 SQL 中使用数据库实时时间函数。

| 参数 | 含义 | 取值 |
|---|---|---|
| `${bizdate}` | 业务日期 | 通常 T-1 |
| `${bizmonth}` | 业务月份 | T-1 所属月 |
| `${gmtdate}` | 当前日期 | 当天 |
| `${gmtmonth}` | 当前月份 | 当天所属月 |
| `${bizdate-N}` | 前推业务日期 | T-1-N |
| `${startdate}/${enddate}` | 调度窗口起止 | 区间任务 |
| `${last_sync_time}` | 上次同步水位 | 增量任务 |

常用写法：
```sql
WHERE ds = '${bizdate}'                       -- 前一天
WHERE ds = '${gmtdate}'                       -- 当天(实时)
WHERE ds BETWEEN '${bizdate-6}' AND '${bizdate}'  -- 近 7 天
WHERE ds BETWEEN '${bizmonth_start}' AND '${bizmonth_end}'  -- 上月整月
```

## 增量与分区刷新策略
| 策略 | 实现方式 | 适用场景 | 代价 |
|---|---|---|---|
| 全量覆盖 | 每次重算全量覆盖分区 | 数据量小、口径变化频繁 | 计算资源大 |
| 增量合并 | 追加后按主键去重 | 源有稳定增量标记 | 去重复杂、易重复 |
| 拉链累积 | 按变更记录拉链存历史 | 需按时间点还原状态 | 存储大、查询带有效期 |

- 增量起始水位必须持久化（调度参数/元数据表），不得用固定日期替代。
- 增量写法见 `templates/incremental_merge.sql`。

## 多表关联与窗口函数
- LEFT JOIN 右表字段必须 `NVL/COALESCE` 兜底并明确无匹配默认值，否则 NULL 被误判为真实空值参与汇总。
- 窗口函数优先标准 SQL，正确示例见 `docs/04-sql-dev.md` 扩展或手册 5.5。

## 性能优化清单
| 优化项 | 做法 | 验证方式 |
|---|---|---|
| 分区裁剪 | 分区列直接过滤、不函数包装 | 看执行计划裁剪结果 |
| 列裁剪 | 显式列字段、不用 SELECT * | 看实际读取列数 |
| 小表广播 | 维表小用 MAPJOIN/广播提示 | 对比 Join 类型 |
| 数据倾斜 | 热点键打散/拆分 | 统计 JOIN 键分布 |
| 长 SQL 拆分 | 多步加工拆中间表 | 对比单步耗时/资源 |
| 文件数量 | 控制输出文件数与大小 | 统计文件数与均值 |
| 中间结果复用 | 公共逻辑上移共享层 | 比对重复实现 |
| 全表扫描 | 避免无分区过滤全表扫描 | 看扫描数据量 |

## 常见反例（必查）
| 问题 | 反例 | 改进 |
|---|---|---|
| 分区裁剪失效 | `WHERE DATE(ds)='2026-11-01'` | `WHERE ds='20261101'` |
| 跨分区膨胀 | 关联子查询未带 ds | 双侧都带 ds |
| 非幂等写入 | `INSERT INTO` 后不清理 | `INSERT OVERWRITE ... PARTITION` |
| 精度丢失 | 金额用 FLOAT/DOUBLE | `DECIMAL(18,4)` |
| 魔法数字 | `WHERE order_status='A01'` | 映射字典/常量参数 |
| 隐式转换 | 关联类型不一致 | 建表阶段类型对齐 |
| N+1 查询 | 循环取数 | 一次拉取后内存/中间表关联 |
| 无边界拉取 | `SELECT * FROM 源表` 无分区 | 强制携带分区条件 |

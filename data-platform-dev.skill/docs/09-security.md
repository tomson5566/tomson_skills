# 9 安全与合规

## 数据分级分类
| 级别 | 典型数据 | 管控要求 |
|---|---|---|
| 公开 | 已对外发布数据、通用字典 | 可对外共享，常规授权 |
| 内部 | 一般业务明细、汇总指标、非敏感配置 | 限内部授权，按需开通 |
| 敏感 | 客户身份信息、联系方式、薪酬、交易明细 | 逐项审批授权、接口鉴权、访问留痕 |
| 重要 | 企业战略、经营与安全核心数据 | 按密级管理，原则上不出数据平台 |

> 分级名称与管控动作企业可自行调整，但应与行业监管要求一致。

## 权限模型
| 角色 | 典型权限 | 边界 |
|---|---|---|
| 数据 owner | 数据定义权与授权审批权 | 不能直接执行生产写入 |
| 数据开发 | 所负责空间开发与发布权 | 不能自行扩大授权 |
| 数据分析师 | 已授权范围内查询取数 | 生产表只读，禁止直接改数 |
| 数据消费方 | 通过接口/数据集取结果 | 不接触底层表 |
| 平台运维 | 资源配置与运行监控权 | 默认不授予定义权 |
| 审计角色 | 日志与变更查阅权 | 只读不可修改 |

- 最小必要原则；人员调岗/离职/结项 3 个工作日内回收权限；每季度复核高权限与长期未使用账号。

## 脱敏与加密
- 敏感字段**贴源层不做脱敏**（保持与源可比对）。
- 共享层及以上按场景脱敏：静态脱敏（入库即脱敏）/ 动态脱敏（查询按权限返回）。
- 标识类字段按用途选：原文存储、掩码展示、哈希替代、完全不出域。
- 个人信息导出/留存/销毁符合法规与制度。
- 测试环境不使用生产敏感数据，用脱敏样本。
- **严禁**敏感数据同步至个人终端、非数据平台存储或未批准第三方。

## 审计留痕（留存一般 ≥ 6 个月）
| 行为类别 | 记录内容 |
|---|---|
| 表访问 | 账号、表名、时间、访问量、来源地址 |
| 接口调用 | 消费方、接口名、入参摘要、返回码、耗时 |
| 权限变更 | 申请人/审批人、权限范围、生效回收时间 |
| 任务变更 | 变更人、内容、影响范围、上线时间 |
| 数据导出 | 账号、数据范围、数据量、审批单号 |
| 生产写入 | 执行账号、目标表、分区、SQL 摘要 |

> 审计日志不得记录明文口令、密钥与完整个人敏感信息；防篡改，与生产数据访问权限相互独立。

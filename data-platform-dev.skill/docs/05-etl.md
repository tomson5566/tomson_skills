# 5 数据集成与同步开发

## 集成模式选型
| 模式 | 实现方式 | 时效性 | 资源 | 适用场景 |
|---|---|---|---|---|
| 全量快照 | 每次导出全表并覆盖 | 取决于调度 | 高 | 小表、无增量标记 |
| 时间戳增量 | 按更新时间窗口拉取 | 分钟~小时级 | 低 | 源表有可靠更新时间字段 |
| 主键增量 | 按自增主键区间拉取 | 分钟~小时级 | 低 | 源表有单调递增主键 |
| 日志捕获(CDC) | 订阅数据库变更日志 | 秒~分钟级 | 中 | 需实时同步且源库支持 |
| 文件交换 | 定时拉取约定目录文件 | 取决于交换 | 低 | 跨组织数据交换 |

> 选型优先级：源库具备可靠增量能力时优先增量；但增量链路必须配水位管理与对账，否则静默丢失比全量更危险。

## 任务命名与核心配置
- 命名：`sy_{源库简称}_to_{目标库简称}_{目标表名}`，如 `sy_mysql_to_hive_dwd_cust_customer`。
- 配置项：源/目标连接(生产凭据运维托管，不写脚本与代码库)、读取模式(分区裁剪/增量水位)、字段映射(显式建对应)、类型对齐(显式精度处理)、写入模式(默认覆盖分区)、并发与限流、失败重试(不重复写脏数据)、独立资源队列。

## 字段映射与类型对齐
| 源端 | 目标端 | 处理说明 |
|---|---|---|
| VARCHAR(n) | STRING | 超长截断须记录，不静默丢弃 |
| INT | BIGINT | 预判溢出 |
| DECIMAL(18,4) | DECIMAL(18,4) | 精度一致直传 |
| TIMESTAMP / DATETIME | STRING | 统一 `yyyy-MM-dd HH:mm:ss`，明确时区 |
| CHAR(n) | STRING | 去除尾部空格 |
| NULL | '' 或 NULL | 按业务语义区分，不一律置空串 |

> 任何截断/精度丢失/时区转换必须在任务注释逐项列出；未经确认的静默转换是数据质量问题主要来源。

## 增量抽取与水位管理
```sql
SELECT * FROM ods_erp_customer
WHERE ds = '${bizdate}'
  AND updated_time > '${last_sync_time}'
  AND updated_time <= '${current_sync_time}'
```
| 水位要点 | 做法 |
|---|---|
| 持久化 | 同步成功后写入元数据表/调度参数作为下批次起点 |
| 推进时机 | 仅目标分区写入成功且校验通过后推进 |
| 断点续传 | 失败重跑沿用原水位，不跳过失败区间 |
| 首次全量 | 首上线执行全量并记录基线水位 |
| 水位回退 | 补数时人工指定水位区间，禁止直接推进到当前 |

## 幂等与前后置语句
- 前置清理目标分区：`DELETE ... WHERE ds='${bizdate}'`
- 后置去重：对同批次重复记录做 ROW_NUMBER 去重
- **仅允许操作本任务自身的目标表与分区**；禁止物理删除或跨表操作。

## 数据校验
| 类型 | 方法 | 通过标准 |
|---|---|---|
| 记录数比对 | 源端/目标端分区行数比对 | 差异在允许范围 |
| 主键去重比对 | 去重后行数 = 源端唯一键数 | 完全一致 |
| 汇总值比对 | 金额/数量 SUM 校验 | 差异为零或小数精度内 |
| 空值率比对 | 关键字段空值率与历史对比 | 无异常上升 |
| 抽样核对 | 按主键抽样比对字段值 | 字段值一致 |

对账模板见 `templates/reconciliation.sql`。

# 刷新周期 / 增量标识 / 部署状态 编码表（可扩展）

## 刷新周期编码
| 刷新周期 | 编码 | 刷新周期 | 编码 |
|---|---|---|---|
| 按分钟 | min | 按周 | w |
| 按小时 | h | 按月 | m |
| 按日 | d | 按季 | q |
| 实时 | r | 按年 | y |

> 示例：`dws_cst_cust_day_stat_d`（日刷新）、`dws_cst_cust_day_stat_df`（日刷新全量）。

## 增量标识编码
| 类型 | 编码 | 说明 |
|---|---|---|
| 增量 | i | 分区数据为相对上一周期的增量 |
| 全量 | f | 分区数据为当前时间点的全量快照 |
| 累积快照 | s | 分区数据为截至当前时点的累计快照 |

## 贴源层增量方式
| 增量方式 | 编码 | 说明 |
|---|---|---|
| 时间戳增量 | inc | 按更新时间字段拉取 |
| 自增主键增量 | idc | 按自增主键区间拉取 |
| 日志变更捕获 | cdc | 基于数据库变更日志 |
| 全量快照 | full | 全表快照覆盖 |

## 部署方式与状态
| 维度 | 取值 | 编码 |
|---|---|---|
| 部署方式 | 集中部署 / 本地部署 | central / local |
| 表状态 | 生产 / 测试 / 废弃 | prd / dev / dep |
| 任务类型 | 批式 / 流式 / 实时计算 | batch / stream / rt |

## 扩展区域
需要新增刷新周期 / 增量标识 / 状态时，直接在上方对应表追加一行即可，命名规范会自动引用。
